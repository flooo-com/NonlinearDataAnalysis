# NonlinearDataAnalysis
University Work for detecting the climate coupling between global volvanic forcing and local climat from Belize for the last 2000 years.


Files:

- The Jupyter Notebook `Project_7_Josephowitz2.ipynb` contains the calculations
- The file `recurrence.py` is a toolset for recurrence analysis
- print settings sets a few paramters for the Matplotlib Plots inside the notebook
- The `Data` Folder contains the used data
